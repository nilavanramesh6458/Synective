Have you tried the Analysis tool in Business Central?

Analysis Tool is closest to the Pivot tool in Excel, so you don’t have to open the Ledger/List in Excel and then run Pivot – you can do this straight within Business Central. Added feature is that you can Save this analysis for future references!

On almost any List page, you can turn on the ‘Analyse’ toggle button at the main menu to start the pivoting.
